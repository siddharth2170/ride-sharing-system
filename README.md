# Ride Sharing System in C++ and Smalltalk

This repository-ready project demonstrates encapsulation, inheritance, and runtime polymorphism with `Ride`, `StandardRide`, `PremiumRide`, `Driver`, and `Rider` classes.

## Run the C++ implementation

```bash
g++ -std=c++17 -Wall -Wextra -pedantic cpp/main.cpp -o ride_sharing
./ride_sharing
```

## Run the Smalltalk implementation

Open Pharo or Squeak, file in `smalltalk/RideSharing.st`, and evaluate the demonstration block at the bottom. Output appears in the Transcript.
